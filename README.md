# pink-calculator
## What I Learned
-Using document.querySelector() to select HTML elements.
-Using the .value property to read and update the calculator display.
-Handling button clicks using JavaScript event listeners.
-Dynamically updating the display based on user interactions.
-Using eval() to evaluate mathematical expressions.
## How It Works
-Users enter numbers and operators by clicking the calculator buttons.
-JavaScript updates the display using the .value property.
-When the user clicks the equals button, eval() evaluates the mathematical expression and displays the result.
-The clear button resets the display
